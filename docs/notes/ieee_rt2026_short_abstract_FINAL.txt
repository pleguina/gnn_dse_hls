Title: Design-Space Exploration and Integer Quantization of Graph Neural Networks for Real-Time FPGA Track Finding

Abstract (text only, <250 words):

Real-time track finding for displaced-muon signatures in the CMS Level-1 trigger must operate under fixed-latency constraints (12.5 μs) while processing high-throughput detector data. Graph neural networks (GNNs) naturally represent sparse, irregular geometries with variable occupancy, but mapping message-passing models from PyTorch Geometric to FPGAs requires careful co-optimization of accuracy, numeric formats, and high-level synthesis microarchitecture.

We present an end-to-end workflow bridging GNN training and FPGA prototyping for a GraphSAGE-based model. The pipeline includes: (i) automated design-space exploration framework across model architecture (hidden dimensions, fixed-point precision), quantization parameters (loop unrolling, accumulator widths), and HLS pragmas to systematically expose accuracy-latency-resource trade-offs via Pareto analysis; (ii) integer-only INT8 implementation with fixed-point scaling and data-driven bit-width optimization, reducing internal accumulator and scaling product widths while maintaining bit-exact validation against Python references; (iii) modular C++ kernels for Vitis HLS synthesis with 0 LSB error in C-simulation on representative subgraphs.

Preliminary results on the Cora proxy dataset show the reduced GraphSAGE model (16→24→7 architecture, 24K parameters) achieves 75.8% accuracy, with post-training quantization (PTQ) maintaining 75.7% (0.1% degradation). Quantization-aware training (QAT) is under active development to improve INT8 performance. HLS C-simulation validates bit-exact agreement between Python and hardware implementations. While the displaced-muon dataset and final track-finder graph construction are in preparation, this methodology establishes a reproducible path toward feasible fixed-latency FPGA designs for GNN-based track reconstruction.
