# Visualization Guide

## Overview

`src/analyze_models.py` generates comparison plots for all model variants (base, reduced, PTQ, QAT, Brevitas, INT8) and saves them to `build/plots/`.

`src/visualization.py` provides the underlying plotting functions.

## Generate All Plots

```bash
# Via pipeline
python run_pipeline.py --skip-training --steps analyze

# Directly
cd src && python analyze_models.py
```

## Generated Plots

All plots are saved to `build/plots/`.

### Training Curves

Generated during training (`src/train.py`, `src/train_qat.py`).

- `build/plots/base_model_training.png` — loss and accuracy over epochs (base model)
- `build/plots/reduced_model_training.png` — loss and accuracy over epochs (reduced model)

Contents: training loss, train/val/test accuracy per epoch.

### Model Comparison

Generated by `src/analyze_models.py`.

- `build/plots/model_comparison.png` — bar charts comparing test accuracy, parameters, and memory across all variants
- `build/plots/efficiency_analysis.png` — accuracy vs parameters and accuracy vs memory scatter plots
- `build/plots/accuracy_degradation.png` — accuracy drop relative to baseline, color-coded by severity
- `build/plots/resource_utilization.png` — parameter breakdown by layer type (conv, linear, other)
- `build/plots/quantization_error.png` — weight distribution before/after quantization, error histogram
- `build/plots/summary_report.png` — multi-panel overview (accuracy, parameters, memory, efficiency, compression)

### Statistics

- `build/plots/model_stats.json` — numerical results for all model variants

## DSE Visualization

After running design space exploration:

```bash
python src/analyze_pareto.py \
    --input build/experiments/design_space_results.json \
    --output build/plots/pareto
```

This generates Pareto front plots (accuracy vs DSP, accuracy vs latency) in `build/plots/pareto/`.

## Using Plotting Functions Directly

```python
from visualization import plot_training_curves, plot_model_comparison

# Training curves
history = {'train_loss': [...], 'train_acc': [...], 'val_acc': [...], 'test_acc': [...]}
plot_training_curves(history, save_path='build/plots/custom_training.png')

# Model comparison
model_stats = [
    {'name': 'Base', 'accuracy': 0.80, 'parameters': 98765, 'memory_mb': 0.4},
    {'name': 'Reduced', 'accuracy': 0.76, 'parameters': 12000, 'memory_mb': 0.05},
]
plot_model_comparison(model_stats, save_path='build/plots/custom_comparison.png')
```

## Customization

Edit `src/visualization.py` to change:
- Figure size: `plt.rcParams['figure.figsize']`
- Font size: `plt.rcParams['font.size']`
- DPI: `plt.savefig(..., dpi=300)`
- Color palette: modify color lists in plotting functions

## Troubleshooting

**Plots not generated**: Verify trained models exist in `build/models/`. Run training first if needed.

**Import errors**: Ensure `matplotlib` is installed (`pip install -r requirements.txt`).

**Memory issues**: Add `plt.close('all')` after generating many plots in sequence.
